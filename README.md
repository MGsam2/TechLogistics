# TechLogistics S.A.

Sistema de Gestión Logística de Inventarios en Tiempo Real.

## Descripción

TechLogistics es una aplicación web desarrollada con ASP.NET Core Blazor para la gestión y monitoreo de inventarios de centros de distribución.

El sistema contempla:

- Monitoreo de inventario en tiempo real.
- Gestión de catálogo.
- Registro de despachos.
- Operación para GerenteBodega y AgenteCampo.
- Comunicación mediante API REST.
- Telemetría mediante gRPC.
- Gestión de estado global y persistente.
- Autenticación y autorización basada en roles.
- Pruebas automatizadas con xUnit y bUnit.
